# نشر نسخة جديدة — ضغطتين على `PUBLISH.bat`

بعد ما تخلّص تعديلاتك على الجهاز، دوس دبل كليك على **`PUBLISH.bat`**. هو هيعمل كل خطوات GitHub لوحده،
وفي الآخر هيفتحلك صفحة الـ Release فيها لينك التنزيل الثابت.

## بيعمل إيه بالظبط

1. **يتأكّد إن كل حاجة جاهزة:** إن Git متسطّب، وإنك على فرع `main`. وبعدين يسحب آخر نسخة من GitHub، عشان ميحصلش تعارض مع تعديل اتعمل من مكان تاني.
2. **يحميك من رفع حاجة غلط.** يرفض النشر لو بين الملفات:
   - قاعدة بيانات (`.db`، `.sqlite`)
   - إعدادات أو مفاتيح (`.local.php`، `.env`، `.pem`، `.key`)
   - نسخ احتياطية، أو صور زيارات المناديب
   - مفتاح دفع مكتوب جوّه أي ملف (`sk_live_…`)
3. **يسألك سؤالين:**
   - **نوع التعديل** (رقم النسخة بيطلع لوحده):
     - `1` إصلاح: من 2.31.0.0 لـ 2.31.1.0 (ده الافتراضي)
     - `2` ميزة جديدة: من 2.31.0.0 لـ 2.32.0.0
     - `3` بناء بس: من 2.31.0.0 لـ 2.31.0.1
   - **إيه اللي اتغيّر** في سطر واحد بالعربي. السطر ده بيظهر في الـ Release وفي `CHANGELOG.md`.
4. **يشغّل الاختبارات** (حوالي 5 دقايق، وتقدر تتخطّاها بـ `n`). لو أي اختبار فشل، النشر بيتلغي ورقم النسخة بيرجع زي ما كان.
5. **يرفع على GitHub:** بيعمل commit و push على `main`، وبيعمل فرع اسمه `v<النسخة>`. الفرع ده بيشغّل البناء على GitHub.
6. **الـ Release بيتعمل لوحده:** البناء بيبني برنامج الويندوز ويجرّبه إنه بيفتح. لو نجح، بيعمل **Release** فيه الملف وبصمته وملاحظات النسخة. ده بياخد حوالي 4 لـ 6 دقايق، والسكربت بيستنّاه ويفتحه لك. ولو قفلت الشباك، الـ Release برضه هيتعمل.

## أول مرة بس

- **Git:** نزّل Git for Windows من https://git-scm.com/download/win.
- **الريبو:** لازم يكون متحمّل على الجهاز (`git clone https://github.com/ammarnabileg/app`)، وتشتغل جوّه الفولدر ده.
- **تسجيل الدخول:** أول push، Git هيفتحلك نافذة تسجيل دخول على GitHub. سجّل مرة واحدة وهيفتكرك.
- **Python (للاختبارات بس):** لو مش متسطّب، اختار `n` لما يسألك عن الاختبارات.

## مهم

- **لينك الـ Release عام:** الريبو عام، فأي حد معاه اللينك يقدر ينزّل الملف. البرنامج نفسه مش بيشتغل من غير ترخيص.
- **التحديث مش بيوصل للعملاء لوحده:** النشر ده مش بيبعت التحديث التلقائي للعملاء. ده لسه خطوة `tools/publish_version.py` بمفتاح اللوحة (`docs/RELEASE.md`).
- **لو حاجة فشلت:** السكربت مش بيرفع حاجة ناقصة. لو فشل قبل الرفع، رقم النسخة بيرجع زي ما كان وتعديلاتك بتفضل زي ما هي.
