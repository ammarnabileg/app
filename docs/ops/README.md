## الصورة الكاملة في عشرة أسطر

```
عميل يسجّل على onz.one
        ↓
لوحة PHP تُنشئ الحساب والترخيص، ثم تضع مهمة في الطابور
        ↓
bin/provision_worker.php (كرون) يسحب المهمة
        ↓
Portainer ينشئ stack للمستأجر: web + sync + adms
        ↓
Traefik يرى الحاوية من labels عليها، ويصدر الشهادة
        ↓
<الشركة>.onz.one يعمل
```

ثم، في الاتجاه المعاكس، جهاز البصمة عند العميل يتصل بنفس العنوان على
المسار `/iclock` ويدفع البصمات.

## ما هو مُشغَّل فعلًا اليوم

التوثيق يصف ما بُني. وهذا ما هو **قيد التشغيل** وقت كتابة هذا الملف:

| | الحالة |
|---|---|
| مستأجر واحد (`jwahr`) على خادم بلِسك | يعمل — أُنشئ يدويًّا قبل الأتمتة |
| التجهيز التلقائي | **لم يُشغَّل على خادم حقيقي بعد** |
| Traefik | **لم يُنشر بعد** |
| خادم أوراكل (ARM) | فارغ |

ابدأ من [الفحص قبل أي شيء](03-provisioning.md#الفحص-قبل-أي-شيء) — يقول لك
في دقيقة أي جزء جاهز فعلًا.
