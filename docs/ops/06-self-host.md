# الاستضافة عند الشركة (Docker) — والوكيل المحلي — والترخيص بدون إنترنت

> فرع `dev1` (لم يُطلق بعد). ثلاث طرق تشغيل، والكود واحد:
>
> | الطريقة | فين البرنامج | أجهزة البصمة الـIP (K40) | الترخيص |
> |---|---|---|---|
> | **ويندوز** (الحالي) | كمبيوتر في الشركة | مباشر | أونلاين، أو ملف موقّع |
> | **أونلاين عندنا** (Coolify) | سيرفرنا | **الوكيل المحلي** | أونلاين |
> | **Docker عند الشركة** | سيرفر الشركة | مباشر (نفس الشبكة) | أونلاين، أو ملف موقّع |

أجهزة **ADMS** (Push) في كل الحالات بتكلّم البرنامج بنفسها — اضبط على الجهاز عنوان السيرفر
والمنفذ (8081)، ومش محتاجة وكيل.

---

## ١) Docker على سيرفر الشركة

المتطلبات: Linux (أو Windows Server عليه Docker)، 2 GB رام، 10 GB مساحة.

```bash
git clone https://github.com/ammarnabileg/app.git hr && cd hr
git checkout v2.37.0.0            # رقم إصدار — مش آخر كود
cat > .env <<'ENV'
COMPANY=acme
WEB_PORT=5000
ADMS_PORT=8081
TZ=Asia/Kuwait
ENV
docker compose -p acme up -d --build
```

- البرنامج: `http://عنوان-السيرفر:5000` — أول دخول بيطلب التفعيل (القسم ٣).
- البيانات كلها في الـvolume `acme_hr_data` (قاعدة SQLite + الصور + المرفقات). إعادة
  البناء أو التحديث ما بتمسحهاش.
- **النسخ الاحتياطي**: من داخل البرنامج (النسخ الاحتياطي ← تنزيل)، أو من السيرفر:

  ```bash
  docker run --rm -v acme_hr_data:/d -v "$PWD":/b alpine tar czf /b/hr-backup-$(date +%F).tgz -C /d .
  ```

  خلّي نسخة يومية تتنقل لمكان تاني غير السيرفر (NAS / سحابة الشركة).
- **التحديث**: `git fetch --tags && git checkout vX.Y.Z.W && docker compose -p acme up -d --build`.
  الترحيل بيحصل لوحده عند الإقلاع (`tools/check_migrations.py` بيتأكد منه قبل كل إصدار).
- **HTTPS** (لو البوابة هتتفتح من موبايلات برا الشركة): حط قدامه nginx / Caddy بشهادة، واضبط
  `BIND=127.0.0.1` في `.env` عشان المنفذ ما يتنشرش من غير تشفير. الكشك والكاميرا محتاجين HTTPS
  لو التابلت مش على نفس السيرفر.
- الأجهزة المباشرة (K40) لازم تكون على شبكة السيرفر نفسه — البرنامج هو اللي بيتصل بيها.

## ٢) الوكيل المحلي — النسخة الأونلاين وجهاز K40 جوه الشركة

السيرفر الأونلاين مش شايف شبكة الشركة، فالبرنامج مش هيقدر يتصل بالـK40. الوكيل برنامج صغير
(`connector_agent.exe`، جنب `HRSystem.exe` في الباكدج) على **أي كمبيوتر ويندوز شغال في
الشركة**:

1. في البرنامج الأونلاين: **الحضور ← إدارة الأجهزة ← «الوكيل المحلي» ← وكيل جديد** —
   هيظهر **مفتاح** مرة واحدة بس.
2. ضيف الجهاز: **إضافة جهاز ← الماركة: «ZKTeco — عبر الوكيل المحلي»**، والعنوان = عنوان
   الجهاز على شبكة الشركة (مثلًا `192.168.1.201`).
3. على كمبيوتر الشركة:

   ```
   connector_agent.exe --setup --server https://acme.onz.one --key onzc_…
   ```

   بيعمل دورة تجربة ويطبع النتيجة. بعدها شغّله في الخلفية (اختصار في Startup، أو مهمة
   مجدولة «عند تسجيل الدخول»): `connector_agent.exe`

كل دقيقتين: يسحب البصمات الجديدة من كل جهاز ويرفعها (نفس قواعد الحضور: الموقوف بصمته بتتسجّل
«متجاهلة»، والرقم الجديد بيستنى لحد ما يتضاف، والتكرار ما بيتحفظش)، وينفّذ الأوامر المنتظرة
(إيقاف موظف بنفس بت «معطّل» من غير ما يتمسح، تفعيل، حذف، رفع موظف، ضبط الوقت). وكل ساعة
يرفع قائمة مستخدمي الجهاز (الجديد بيتضاف موظف بإشعار «كمّل بياناته»). وقبل ما يوقف أو يمسح
موظف، بيرفع بصماته للسحابة عشان لو رجع.

- الإعداد والسجل: `C:\ProgramData\onz_connector\config.json` و `connector.log`.
- الكمبيوتر اتقفل؟ البصمات فاضلة على الجهاز، وأول ما يرجع بيكمّل من بعد آخر بصمة وصلت
  (بتداخل ١٠ دقايق). والأوامر بتستنى في الطابور وبتتعاد.
- المفتاح اتسرّب؟ «مفتاح جديد» من نفس الشاشة — القديم بيبطل فورًا.

## ٣) الترخيص بدون إنترنت

البرنامج بيتأكد من الترخيص أونلاين، ولو النت قطع بيشتغل **بالرخصة الموقّعة** اللي بتنزل مع
كل تحقق ناجح لحد تاريخ انتهائها. لجهاز **عمره ما اتوصل بالنت**:

1. صفحة الترخيص ← «الجهاز ده مش متوصل بالإنترنت خالص؟» ← انسخ **كود الجهاز**.
2. ابعته للدعم، وهيرجعلك **ملف ترخيص** (`ONZ1.…`) موقّع لكود الجهاز ده بالتاريخ المدفوع.
3. نفس الصفحة ← اختار الملف (أو الصق النص) ← «تفعيل بالملف».

الملف موقّع بمفتاحنا الخاص والبرنامج فيه المفتاح العام بس — يعني مينفعش يتزوّر، ولا يتعدّل
تاريخه، ولا يشتغل على جهاز تاني. التجديد = ملف جديد بنفس الطريقة.

> **ناقص في لوحة الإدارة:** زرار «إصدار ملف ترخيص بدون إنترنت» لعميل + كود جهاز (اللوحة نفسها
> بتوقّع الرخص دي فعلًا مع كل تحقق أونلاين؛ الناقص الشاشة بس). لحد ما يتعمل، الدعم يطلّعه من
> نفس دالة التوقيع.
