# نظام إدارة الموارد البشرية المتكامل

نظام شامل ومتطور لإدارة الموارد البشرية مبني على Flask مع قاعدة بيانات SQLite، يتضمن نظام بصمة متكامل لمراقبة الحضور والانصراف.

## المميزات الرئيسية

### 🏢 إدارة الموظفين
- إضافة، تعديل، وحذف بيانات الموظفين
- إدارة الأقسام والمناصب
- تتبع تاريخ التوظيف والرواتب
- إدارة معلومات الاتصال والعناوين
- البحث والفلترة المتقدمة

### 💰 إدارة الرواتب
- حساب الرواتب الشهرية
- إدارة البدلات والخصومات
- تتبع سجل المدفوعات
- تقارير الرواتب الشاملة
- حساب تلقائي للصافي

### 🏖️ إدارة الإجازات
- طلبات الإجازات المختلفة (سنوية، مرضية، طارئة)
- نظام الموافقة والرفض
- تتبع رصيد الإجازات
- إشعارات تلقائية
- أنواع إجازات قابلة للتخصيص

### ⏰ إدارة الشفتات
- جدولة شفتات العمل
- تتبع ساعات العمل
- حساب الإضافي
- تقارير الشفتات
- ملاحظات إضافية

### 📄 إدارة الوثائق
- رفع وإدارة وثائق الموظفين
- تصنيف الوثائق حسب النوع
- تحميل ومراجعة الوثائق
- أرشفة آمنة
- دعم ملفات متعددة (PDF, DOC, صور)

### 🔐 نظام البصمة المتكامل
- **ربط أجهزة ZKTeco**: دعم كامل لأجهزة البصمة ZKTeco
- **مزامنة تلقائية**: جلب سجلات الحضور تلقائياً
- **مراقبة في الوقت الفعلي**: عرض الحضور والانصراف مباشرة
- **تقارير شاملة**: تقارير شهرية وسنوية للحضور
- **إحصائيات متقدمة**: نسب الحضور والغياب
- **تصدير البيانات**: تصدير التقارير بصيغة Excel
- **حساب ساعات العمل**: حساب تلقائي لساعات العمل
- **ربط مع الموظفين**: ربط سجلات البصمة مع بيانات الموظفين

## التقنيات المستخدمة

### Backend
- **Flask 2.3.3**: إطار العمل الرئيسي
- **SQLite**: قاعدة البيانات
- **pyzk 0.9.0**: مكتبة ربط أجهزة البصمة ZKTeco

### Frontend
- **Bootstrap 5**: تصميم متجاوب
- **Font Awesome**: الأيقونات
- **JavaScript**: التفاعل والوظائف المتقدمة
- **RTL Support**: دعم كامل للغة العربية

### الأمان
- **Session-based Authentication**: نظام تسجيل دخول آمن
- **CSRF Protection**: حماية من الهجمات
- **Input Validation**: التحقق من المدخلات

## التثبيت والتشغيل

### المتطلبات

- Python 3.8 أو أحدث
- pip (مدير حزم Python)
- أجهزة بصمة ZKTeco (اختياري)

### خطوات التثبيت

1. **استنساخ المشروع**:
```bash
git clone <repository-url>
cd hr-system
```

2. **إنشاء بيئة افتراضية (اختياري)**:
```bash
python -m venv venv
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate
```

3. **تثبيت المتطلبات**:
```bash
pip install -r requirements.txt
```

4. **تشغيل التطبيق**:
```bash
python app.py
```

5. **فتح المتصفح**:
```
http://localhost:5000
```

#### نظام البصمة
- **fingerprint_devices**: أجهزة البصمة المسجلة
- **attendance_records**: سجلات الحضور والانصراف
- **fingerprint_settings**: إعدادات نظام البصمة

#### النظام
- **users**: مستخدمي النظام
- **system_settings**: إعدادات النظام العامة

## إعداد نظام البصمة

### 1. إعداد الأجهزة

#### إضافة جهاز بصمة جديد:
1. انتقل إلى "نظام البصمة" > "إدارة الأجهزة"
2. اضغط على "إضافة جهاز جديد"
3. أدخل البيانات التالية:
   - **اسم الجهاز**: اسم وصفي للجهاز
   - **عنوان IP**: عنوان IP الخاص بالجهاز
   - **المنفذ**: رقم المنفذ (افتراضي: 4370)

#### اختبار الاتصال:
- استخدم زر "اختبار الاتصال" للتأكد من صحة الإعدادات
- تأكد من أن الجهاز متصل بالشبكة ومتاح

### 2. ربط الموظفين

#### تطابق الأرقام:
- تأكد من أن أرقام الموظفين في النظام تتطابق مع أرقام البصمة في الأجهزة
- يمكن تعديل أرقام الموظفين من صفحة "إدارة الموظفين"

### 3. المزامنة

#### المزامنة اليدوية:
1. انتقل إلى "نظام البصمة"
2. اضغط على "مزامنة الأجهزة"
3. انتظر حتى تكتمل العملية

#### المزامنة التلقائية:
- يمكن إعداد المزامنة التلقائية من إعدادات البصمة
- النظام يدعم المزامنة كل 30 دقيقة

### 4. مراقبة الحضور

#### عرض السجلات:
- انتقل إلى "سجلات الحضور والانصراف"
- استخدم الفلاتر للبحث حسب الموظف أو التاريخ

#### التقارير:
- انتقل إلى "تقرير الحضور"
- اختر الشهر والسنة
- تصدير التقرير بصيغة Excel
